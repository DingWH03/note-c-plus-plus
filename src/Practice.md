# C++实践

语言语法只是起点，真正把 C++ 用起来还需要面对工程层面的问题：并发程序怎么写、文件怎么读写、网络怎么通信、服务之间怎么调用。

本章收录这些偏工程实践的内容。与前面的语言特性和标准库章节不同，这里的主题往往涉及操作系统接口、第三方库或平台差异，因此在可移植性和使用方式上需要额外留意。

| 主题 | 说明 |
| :--- | :--- |
| **多线程** | 待补充：线程创建、同步原语、线程池与并发模式。语言层面的并发设施见 [多线程与并发](./Advance/Concurrency.md) |
| **文件与流** | 标准库的输入输出体系，包括控制台、文件与内存字符串三种流 |
| **网络** | 待补充：Socket 编程、TCP/UDP、IO 多路复用 |
| **gRPC** | 待补充：Protobuf 定义服务、C++ 客户端与服务端实现 |

## 文件与流

C++ 把所有输入输出统一抽象为**流（stream）**，无论数据来自键盘、磁盘还是内存，都通过同一套接口读写。这一组文档从流的基本概念讲起，依次介绍三种常用的流类型：

- [文件与流](./Practice/Stream.md)：流模型与类层次结构总览
  - [标准输入输出流 (iostream)](./Practice/Stream/Iostream.md)：`cin` / `cout` / `cerr` / `clog` 与格式化控制
  - [文件流 (fstream)](./Practice/Stream/Fstream.md)：文件读写、打开模式与错误处理
  - [字符串流 (sstream)](./Practice/Stream/Sstream.md)：内存字符串的解析与拼接
